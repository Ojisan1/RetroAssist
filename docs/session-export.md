# Session Export

Session export is a **first-class** RetroAssist deliverable: a clean markdown log for review and expert evaluation.

## Format

Generated by `retroassist.agent.export.session_to_markdown`:

```markdown
# RetroAssist session `<uuid>`

- Created: <UTC timestamp>
- Task tags: ...

## Intake
- Timestamp / Symptom / Visual notes

## Observations
### Observation N
- Summary, meter reading, vision latency

## Retrieval
### Retrieval N
- Query and cited hits (or explicit empty-KB note)

## Suggestions
### Suggestion N
- Action, expected result, rationale, confidence, safety notes, citations

## Measurements / technician reports

## Latency notes

## Event log
```

## API

```python
md = agent.export_markdown()
agent.export_to_path("session.md")
```

Exports must not invent documentation citations when the knowledge base is empty.
