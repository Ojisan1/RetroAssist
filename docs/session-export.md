# Session Export

Session export is a first-class deliverable: clean markdown (or similar) logs of a diagnostic session for review and expert evaluation.

Expected contents (Phase 5+):

- Timestamps
- Intake (symptom + visual notes)
- Observations from vision analysis
- Retrieval citations when available
- Suggestions and user-reported measurements
- Latency notes where recorded

Exact format and CLI/UI export paths will be specified when the agent loop is implemented. See the execution plan for timing relative to the vertical-slice gate.
